Cacharelo · Owner Business Copilot

Un asistente con límites de negocio,
no un usuario con acceso total.

El Copiloto ayuda al propietario a consultar datos y entenderlos en español. Gemini interpreta y redacta; el backend conserva el control de identidad, datos, permisos y cualquier cambio.

Solo propietario autenticadoGemini solo en el servidorLecturas permitidasCambios requieren confirmación

Ruta de una consulta segura

1. PropietarioPregunta: “¿Cómo van las ventas hoy?”
→
2. GeminiClasifica la intención permitida.
→
3. API seguraValida JWT/rol y ejecuta solo la herramienta autorizada.
→
4. Datos + resumenObtiene el reporte, lo redacta y Gemini lo resume en español.

Gemini no recibe la llave del navegador, no llama a MCP y no decide permisos. Si Gemini no responde, el sistema usa una respuesta local segura.

Qué puede hacer hoy

✓
VentasConsulta un resumen de ventas y lleva al reporte correspondiente.
✓
Alertas de inventarioConsulta alertas activas y lleva al panel de inventario.
✓
ProponerPuede proponer orden de compra o cambio de precio.
✕
No modifica en automáticoAún no existe un ejecutor de escrituras; una confirmación sola no cambia nada.

🟢 Ejemplo: lectura

1
“¿Qué alertas de inventario tengo?”
2
Gemini selecciona inventory_alerts.
3
La API consulta la fuente permitida.
4
Gemini resume los datos y muestra la fuente enlazada.

🟠 Ejemplo: cambio de precio

1
“¿Puedes cambiar el precio de los pastes?”
2
Se crea propuesta update_product_price.
3
El propietario revisa producto y monto, luego confirma.
4
Hoy: se detiene de forma segura. Futuro: ejecutor tipado + token de un uso.
🔐
Regla clave: una frase en el chat nunca es una orden de escritura. Para modificar datos se necesita una propuesta tipada, revisión humana, token de confirmación con vencimiento y un ejecutor explícito.

Auditoría: conversación, mensajes, herramientas y confirmaciones se guardan redactados cuando la migración de auditoría esté aplicada. La clave Gemini vive únicamente en Secret Manager/Cloud Run, nunca en el navegador.
