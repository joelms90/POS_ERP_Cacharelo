# Data Model: Tauri Business Control Admin UI

This document outlines the TypeScript interface structures and application state models used in the Tauri React frontend for administrative business controls.

---

## 1. Employee (User Access)

**Purpose**: Represents an employee profile registered in the system with credentials to log into POS terminals.

**Interface**:
```typescript
interface Employee {
  id: string;      // UUIDv4 generated by the backend
  name: string;    // Full name of the employee
  pin: string;     // Unique 4-digit numeric login PIN
  role: 'waiter' | 'cashier' | 'kitchen'; // Employee's job role
}
```

**Validation Rules**:
- `name`: Cannot be empty, maximum 50 characters.
- `pin`: Must be exactly 4 digits, containing only numbers `0-9`. Must be unique across all active profiles.
- `role`: Must be one of the three predefined role strings.

---

## 2. AdminSession

**Purpose**: Manages the authentication state of the administrator controlling the application.

**Interface**:
```typescript
interface AdminSession {
  token: string | null;         // Authentication token (admin password)
  isAuthenticated: boolean;     // Flag indicating successful unlock
  lastActiveTimestamp: number;   // Epoch time for auto-lock timeout calculations
}
```

---

## 3. SystemHealth

**Purpose**: Tracks the operational state and configuration of the sync server backend and its primary database.

**Interface**:
```typescript
interface SystemHealth {
  apiOnline: boolean;           // true if the backend server port is reachable
  databaseConnected: boolean;   // true if PostgreSQL or JSON file system is ready
  databaseType: 'PostgreSQL' | 'Local JSON File'; // Storage backend used by the server
  activeSessionsCount: number;  // Number of active POS terminals connected
}
```

---

## 4. UI Notification State

**Purpose**: Controls the messaging queue for success, error, and connection warning toast notifications.

**Interface**:
```typescript
interface ToastNotification {
  id: string;
  message: string;
  type: 'success' | 'error' | 'warning';
  durationMs: number;
}
```
