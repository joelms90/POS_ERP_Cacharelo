# Quickstart: Verify Active Sucursal Version Display

1. Configure a POS terminal for a known sucursal and sign in with any supported operational role.
2. Open each role dashboard that shows the application version.
3. Confirm the version area identifies the configured sucursal.
4. Reconfigure the terminal to another sucursal and confirm the display updates after configuration is loaded.
5. Check a narrow viewport and a long branch name; no header content may overflow horizontally.
6. Open the unconfigured terminal/login state; it must show only the application version.
7. Run `flutter analyze` from `apps/pos_flutter`.
